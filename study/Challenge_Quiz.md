# Practice and feedback

The studio has 338 study questions and 114 authored multiple-choice challenges.
Every question can be practiced aloud. Quiz availability is shown for the current
selection before a session starts.

## Choose a session

Open Practice or choose Prepare for an interview from the home screen. Select a
topic, optional subtopic and learning level. A selection transferred from Learn
keeps its level filter. Choose all questions, new questions or retry mistakes,
then choose 5, 10, 20 or all eligible questions. More settings contains the optional
text search and the coverage explanation.

Practice this path starts spoken practice for the complete authored path, including
its different levels. This does not change a question's original interview rubric.

## Try before revealing

In Interview practice, explain the answer aloud, reveal the model answer and
self-rate 0-3. Ratings 0-1 enter the retry pool; 2-3 indicate your own readiness
assessment. The app does not record a microphone or grade speech automatically.

In Multiple-choice quiz, select one option and check it. Read the explanation for
your choice and the alternatives, then continue. A correct answer earns XP only
the first time for that concept. Quiz success does not set spoken readiness.

Question and option order are shuffled. Skip for now leaves an item unattempted.
Finish session reports only submitted answers: skipped questions are not mistakes.
Use the results to retry weak answers or practice items not attempted.

## Use the library alongside practice

Global search ignores the current filters. Opening a question during practice
preserves the active session in memory; Resume practice returns to it. Switching
EN/RU preserves that session too. Reload does not preserve an unfinished queue.

Explanation, Code and Step by step are views of the same question. Use the worked
example to predict a value, saved state or error before revealing the next step.
Compare your reasoning with the explanation and relevant source contract. Return
to weak material later and try again without notes.

Visited path items, saved bookmarks, quiz attempts and spoken readiness represent
different things. Reading alone does not establish mastery. Progress stays in the
current browser; there is no account sync or progress import/export interface.

[learning guide](../docs/Learning.md) for the meaning of Core, Applied and Advanced.
