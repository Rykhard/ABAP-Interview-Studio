# Practice sessions and source-guided review

Open START_HERE.html and choose Practice. A single session builder offers Interview practice and Multiple-choice quiz, with each format's coverage visible before starting. Learn remains the complete, freely browsable question library.

## Choose a practice session

Practice defaults to Interview practice across all questions and levels. Choose a topic and optional subtopic, select All questions, New questions or Retry mistakes, then choose 5, 10, 20 or all available questions. The Start button shows the actual session size; a smaller selection uses the questions available. More settings contains optional difficulty and search filters. The format cards show coverage before the new/retry filter; the selection counts and Start button show the eligible pool and planned session.

Quiz status uses the latest submitted answer. Interview practice uses your latest self-rating: 0 or 1 means retry, 2 or 3 means ready. Legacy ready flags are respected. Reading or revealing an answer alone does not count as an attempt. New and retry status stay separate for the two formats.

A session keeps a fixed question list while you answer. Skip for now leaves a question unattempted; Finish session opens results for the answers submitted so far. Neither action marks an unanswered question wrong.

Use Search all topics and questions, or Ctrl+K / Cmd+K, to look up a concept across all 329 questions, answers, examples and source titles. Global search ignores topic and practice filters; Filter this view by text or ID only narrows the current selection. Opening a search result provides controls to return to results or view the question in its topic. Browser Back and Forward follow these navigation paths.

Searching and reading a question keep your current practice session in memory. Resume practice returns to its fixed question list and position within the same page. Reload does not restore an unfinished session. In Learn, Show all answers and Questions only mark the active display with a check and dark background and remember the preference locally. A mixture of individually opened and closed answers is labeled Custom view. Question cards have no difficulty badges.

## Multiple-choice quiz

Each authored quiz question has four choices, one best answer under the stated constraints, and an explanation for every choice. Question and option order are shuffled each session. Select an option and press Check answer; choices then lock. After checking, compact primary references appear immediately below the question. Expand Full explanation & diagrams below the result for the model answer. Diagrams use the same preview, switcher and zoomable viewer as Learn. Senior probes and verification evidence expand under Go deeper. Open the source links in a new tab to investigate the mechanism and target-release restrictions.

A correct answer earns 10 XP only the first time that concept is answered correctly. Repeating it increases attempt statistics without adding XP. New questions includes concepts without a recorded quiz attempt. Retry mistakes includes concepts whose latest recorded attempt was incorrect, even if an earlier answer was correct.

## Interview practice

All 329 questions are available in this format. Explain the decision, trade-off and verification evidence aloud before revealing the model answer. Compare your explanation, then select Not yet (0), Partial (1), Ready (2) or Strong answer (3). The application neither records your microphone nor grades spoken answers automatically. Self-ratings of 2 or 3 mark the question ready; ratings of 0 or 1 put it in the retry selection.

## Session results

Results show how many questions were answered or self-rated, how many were correct or ready, how many need retry, and how many were not attempted. Quiz accuracy is calculated only from submitted answers. Interview practice shows self-rated points only for rated questions. A skipped question or an early finish does not inflate the count of mistakes.

Use Retry mistakes or Retry weak answers to repeat the unsuccessful answers from this session. Practice not attempted continues with skipped and remaining questions. New session returns to the setup. Review questions and explanations lists every session question with its result, model answer, sources and visuals.

## Use the feedback actively

1. State your decision before choosing an option.
2. After checking, explain why each distractor is wrong under the stated constraint.
3. Read the linked answer and predict the visual's worked outcome before its caption.
4. Open the question's source and check the applicable edition, version and API contract.
5. Switch to Interview practice and explain the answer in 90 seconds without options.

Quiz recognition does not establish senior readiness. Oral scores are your own 0-3 judgments against the supplied evidence criteria. Quiz results never set the ready flag automatically.

## Progress and portability

Progress is local to the browser origin/profile. Export it from Downloads & progress before changing devices or opening the pack under a different address. Import accepts earlier v1 ready-list and v2 self-rating exports, plus v3 exports containing quiz progress. Ready flags and ratings are merged; a v3 import restores the exported quiz snapshot. Unknown question IDs are ignored, and malformed recognized data rejects the import before changing progress.

Reload preserves submitted quiz attempts, saved self-ratings and XP, but not an unfinished session or its question order. Ending a session keeps already-submitted results. No account, server or leaderboard is needed; this is personal practice rather than a secure examination.
