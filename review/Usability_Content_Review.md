# Content and usability review

The October 2026 review covered all 329 study questions and 103 authored multiple-choice challenges. Eighteen study questions/reference sets and three quiz items were refined. IDs, levels and answer keys were preserved. Primary-source checks were selective; exact SAP feature availability still needs target-product/release verification.

The app uses one subject tree with subtopics and all difficulty levels together. It supports an explicit, persistent answer-display preference, compact diagram previews with zoom, a global search separate from scoped filters, and independent spoken/quiz readiness. Browser navigation and keyboard focus were checked. Search results can be read while preserving an in-memory practice session; Resume practice returns to it. Reload does not restore unfinished sessions.

Desktop and mobile browser scenarios, progress import compatibility, JavaScript syntax, content/export consistency, local links and PDF bounds/completeness were checked. The changed handbook, practice workbook and quick-revision PDF pages were inspected visually. No SAP runtime, ATC, ABAP Unit, real service integration, desktop Anki import or full accessibility certification is claimed.

Selected accessibility patterns follow the [WAI-ARIA button guidance](https://www.w3.org/WAI/ARIA/apg/patterns/button/) and [modal dialog guidance](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/). Learners should be able to see the selected mode, navigate with a keyboard and return from a dialog to a meaningful location.
